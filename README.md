# qPCR小助手 🐱

Windows 桌面 qPCR 相对定量计算工具 · 猫医生图标 · 学术交流版 0.8

整理 Ct 数据、算 2^(-ΔΔCt)、检查技术重复、出图。

## 下载

去 [Releases](https://github.com/claritycheng/qpcr-helper/releases/latest) 下载 `qPCR-Helper-v0.8-Windows.zip`，解压运行 EXE 就行，不用装 Python。Windows 64 位可用；别的电脑能不能跑，欢迎反馈。

## 激活

本工具用于学术交流。一机一码用于与使用者建立联系，交流使用体验与改进建议。

1. 第一次打开，软件会显示并复制本机设备码。
2. 把完整设备码发到 [**501919931@qq.com**](mailto:501919931@qq.com)，邮件主题写「qPCR小助手设备激活」。
3. 作者人工回复 `.qpcrlic` 激活文件，长期有效，不是即时回复。
4. 再打开软件，导入这个文件就能用。

反馈自愿，不作为持续使用的条件。激活后离线也能用，不用定期联网验证。换电脑或重装系统导致设备码变了，邮件联系作者重新签发。旧版有效授权继续能用；旧授权要是有期限，邮件申请长期激活。

## 功能

- 导入 Excel / CSV，或直接粘贴表格；附简单模板。
- 按样本分别汇总目标基因、内参的技术重复。
- 算 ΔCt、ΔΔCt 和相对表达量，导出 CSV。
- 检查重复 Ct 极差、单孔等情况，只标记不自动剔除。
- 画各组均值、SD 和独立样本散点，保存 PNG / PDF / SVG。

详见 [使用说明](使用说明.md)。

## 数据与设备码

计算全在本机，软件不会自动上传实验数据、设备码或使用记录。设备码是 Windows 机器标识加产品标识做 SHA-256 得到的，用来匹配激活文件；它仍是稳定的设备标识，私下发就行。授权和状态存在当前 Windows 用户的本地应用数据目录。

## 计算边界

用的是单内参 2^(-ΔΔCt)，扩增效率、内参稳定性这些条件得自己确认。软件不自动判断熔解曲线、NTC、扩增效率，也不做跨板校正、显著性检验。技术重复不等于独立生物学重复。正式用之前，拿已知数据对一遍。退出前先导出结果，当前版本不自动保存分析项目。
