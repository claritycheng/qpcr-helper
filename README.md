## 功能

- 导入 Excel / CSV 或粘贴表格；提供简单模板。
- 按样本分别汇总目标基因、内参的技术重复。
- 计算 ΔCt、ΔΔCt 和相对表达量，导出 CSV。
- 检查重复 Ct 极差、单孔等情况；标记数据不自动剔除。
- 绘制各组均值、SD 和独立样本散点，保存 PNG / PDF / SVG。

## 数据与设备码

计算在本机进行，软件不自动上传实验数据、设备码或使用记录。设备码由 Windows 机器标识加产品标识进行 SHA-256 运算得到，用于匹配激活文件；它仍是稳定的设备标识，请按上述方式私下发送。设备授权与状态保存在当前 Windows 用户的本地应用数据目录。

## 计算边界

采用单内参 2^(-ΔΔCt) 方法，需要确认扩增效率、内参稳定性等实验条件适用。不自动判断熔解曲线、NTC、扩增效率，不做跨板校正或显著性检验。技术重复不等于独立生物学重复。正式使用前请用已知数据核对结果。退出前请导出结果，当前版本不自动保存分析项目。
